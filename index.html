Operating doctrine

Adapted from quantitative research
01

Models interpret. Code decides.

Every consequential call runs in deterministic, versioned code.

02

Fail closed.

Ambiguity halts the pipeline. The system escalates with a coded reason instead of shipping a plausible error.

03

Replayable by default.

Source hash, model, rules version and checks are recorded for every run.

04

Autonomy is earned.

Agents unlock authority only against measured reliability. Irreversible actions require sign-off.

05

Pre-registered acceptance.

Pass criteria are fixed before the build. Validation runs on held-out data.
